# Better-Twitter  
A Tampermonkey script that lets you Block Users + Remove Promo + Grok Cleaner + Analytics Blocker

[![Button Install]][Script]   *Requires [Tampermonkey](https://www.tampermonkey.net/) extension*

## Usage
1. Install the Tampermonkey extension
2. Click the Install button above
3. Refresh Twitter/X to activate
